# 파일 업로드 서버

Node.js 18 이상. 추가 패키지 설치 없이 실행합니다.

```powershell
node server.js
```

브라우저에서 http://127.0.0.1:3000 접속 후 파일을 선택합니다.
파일은 이 프로젝트의 `uploads` 폴더에 저장되며, 중복을 피하기 위해 이름에 고유 ID가 붙습니다.
파일 용량과 업로드 시간 제한은 없습니다. 저장 가능한 용량은 디스크 여유 공간에 따라 달라집니다.
업로드 중 실패하면 불완전한 파일을 삭제합니다.
서버 종료는 Ctrl+C입니다.

기본적으로 같은 네트워크의 다른 기기에서도 접속할 수 있습니다.
이 컴퓨터에서만 접속하도록 제한하려면:

```powershell
$env:HOST='127.0.0.1'
node server.js
```

다른 기기에서 `http://이컴퓨터의IPv4주소:3000`으로 접속합니다. IP는 `ipconfig`로 확인합니다.
Windows 방화벽이 요청하면 개인 네트워크 접근을 허용해야 합니다.
인증이 없으므로 신뢰하는 내부 네트워크에서만 사용하세요.
포트는 `$env:PORT='3001'`로 변경할 수 있습니다.

검증: `npm test`

업로드 현황: http://127.0.0.1:3000/status (이 컴퓨터에서만 접속 가능).
받은 용량, 진행률, 평균 속도와 완료/실패 상태를 1초마다 표시합니다.
내역은 메모리에 보관하며 서버 재시작 시 초기화됩니다.

로컬 현황 페이지의 '다운로드 파일 공유'에서 파일의 전체 경로를 등록하면
일반 업로드 페이지 아래에 다운로드 링크가 표시됩니다.
파일을 복사하거나 업로드하지 않고 경로만 메모리에 등록합니다.
공유 해제나 서버 종료 시 목록에서 사라지며 원본 파일은 삭제하지 않습니다.
등록된 파일은 같은 네트워크에서 서버에 접속 가능한 기기가 다운로드할 수 있습니다.
